# Аудит и рефакторинг

Проверено на Linux, 15 сентября 2026 года. Исходной точкой служило рабочее дерево
с незавершёнными пользовательскими изменениями, а не HEAD. Изменения оформления,
кэша и плеера из этого дерева сохранены. Новые зависимости не устанавливались.

## Ответственность модулей

- `app`: запуск, авторизация и сборка библиотеки. `Library.tsx` координирует features;
  чистое описание текущего представления выделено в `libraryPresentation.ts`.
- `layouts/wide`: размещение sidebar, таблицы, плеера и полноэкранного просмотра.
- `features`: предметное состояние, запросы, действия и компоненты.
  Очистка теперь принадлежит storage, контекст воспроизведения — player,
  мозаика с загрузкой обложек — tracks.
- `shared`: контракты, общие примитивы, настройки энергосбережения и тип навигации
  `View`. Импорты из app, layouts и features устранены.
- Rust: `commands` адаптируют Tauri-вызовы, `service` выполняют сценарии,
  `repository` инкапсулируют SQL. `shared/telegram` владеет транспортом и файловой
  сессией; обратный импорт хранилища из auth устранён.

AGENTS.md не найден. Изучены package.json, оба tsconfig, eslint.config.js,
Cargo.toml и `.github/workflows/check.yml`. Упомянутого в Cargo.toml STYLE.md нет.
Граф TypeScript-импортов проверялся по AST, включая импорты типов.

## Контракты

Track и ProfileTrack не объединялись: второй описывает музыку Telegram-профиля,
в том числе отсутствующую в локальной библиотеке. Его document_id остаётся строкой.
Серверные Option сериализуются в null; frontend-состояния загрузки с undefined
сохраняют самостоятельный смысл. FetchProgress — локальное представление события,
а PlaybackState — ответ аудиодвижка, это также разные контракты.

Tauri-команды, их регистрация, серверные модели и файл реализации сессии сравнены
с исходным рабочим деревом. Форматы команд, событий, БД, настроек и резервных копий
не менялись. Все CSS-файлы совпадают с исходными с учётом переносов; исключение —
обновлённый путь в одном комментарии.

## Проверки и ограничения

- `npm run typecheck` и `npm run build` прошли.
- Шесть тестов Node проверяют группировку, все виды представления и режимы repeat,
  неизвестный JSON, legacy fallback, пустые строки, null, false, ноль и границы чисел.
  Команда `npm test` добавлена в package.json и frontend job CI. Используется Node 22,
  как в существующем CI, и уже установленный TypeScript; новых библиотек нет.
- `cargo clippy --all-targets --locked --offline -- -D warnings` прошёл.
- `cargo test --locked --offline`: 58 прошли, один тест живого аудиосервера пропущен;
  в числе пройденных — три теста перенесённой файловой сессии.
- Rust formatting и `git diff --check` проходят.
- До правок ESLint сообщал 43 предупреждения без ошибок. Разделение контекста
  убрало предупреждения Fast Refresh у PlayerProvider. После преобразования
  TrackTable линтер начал сообщать о существовавшем `Date.now()` при отрисовке;
  время вычисления признака NEW сохранено, чтобы не менять поведение.
- Общий Prettier check по-прежнему сообщает об исходном `TrackLyrics.css`.
  Исходный формат WideLayout исправлен при форматировании затронутого файла.
- Vite предупреждает о размере bundle и сочетании статического и динамического
  импорта Tauri core. Деление bundle не входило в изменения.

Не проверены Windows, визуальное сравнение в WebView и живые Telegram-сценарии.
Не изменялись: экранная машина авторизации, побочные эффекты очереди, настройка
получения текстов песен, оставшиеся React-предупреждения, сборка SettingsProvider
и история artistScope в Library. У числовых i64 Telegram-полей существует ограничение
точности JavaScript; изменение их wire-формата требует отдельной миграции.
